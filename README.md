# Northstar Performance Enablement Prototype

Interactive static prototype covering the full performance journey for HR, managers, and employees.

## Run

No build, package install, or backend is required. From PowerShell in this folder, run:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\server.ps1 -Port 4173
```

Then open http://localhost:4173.

## Prototype flows

- Switch between HR, manager, and employee roles.
- Launch a review cycle with rule-based auto-enrollment.
- Track scheduled, completed, pending, and at-risk reviews.
- Compare employee appraisals as a continuum.
- Open an employee to see three-year history, goals, skills, 360 feedback, and balanced scorecard data.
- Complete rating, ranking, bell curve, salary, position, succession, development, and communication recommendations together.
- Route promotions, grade changes, and salary changes through multi-level approval.
- Print the full appraisal detail view.
